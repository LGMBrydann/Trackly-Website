# Trackly_

Trackly_ is a Twitch bot that brings Last.fm music tracking directly into Twitch chat.

## Features

- Twitch OAuth
- Persistent authorized channels
- Last.fm integration
- `=` command prefix
- Now Playing
- Recent tracks
- Top tracks
- Top artists
- `=say`

## Technology

- Cloudflare Pages
- Cloudflare Workers
- Cloudflare D1
- Twitch API
- Twitch OAuth
- Twitch EventSub
- Last.fm API

🚧 Currently in development.
